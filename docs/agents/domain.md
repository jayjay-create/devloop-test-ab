# Domain

- Glossary: `CONTEXT.md` at the repository root. Terms go in the moment they come up, not collected later.
- Decision records: `docs/adr/`.

A decision gets a record when all three hold: it is hard to reverse, surprising without explanation, and the result of a real trade-off.

Format: title, context, decision, binding consequences, status (only for superseded or deprecated), rejected options (only when the rejection is not obvious), and one line: "What would make this decision invalid".
